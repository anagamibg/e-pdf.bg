# e-pdf.bg — безплатни PDF инструменти

[e-pdf.bg](https://e-pdf.bg) е безплатно онлайн приложение за работа с PDF файлове: обединяване, компресиране, конвертиране, редактиране, защита с парола и отключване. Интерфейсът е на български (по подразбиране) и английски.

**Версия:** 1.8.0

## Как се ползва

Всички инструменти следват един и същ поток:

1. Избирате инструмент от началната страница или от менюто в хедъра (има и търсачка).
2. Качвате файл — чрез бутона или с плъзгане върху полето за качване. Лимит: 40 MB на файл.
3. Подреждате/настройвате — според инструмента: пренареждане на страници, избор на качество, въвеждане на парола, избор на диапазони.
4. Натискате основния бутон и изчаквате обработката.
5. Изтегляте резултата. Файловете на сървъра се изтриват автоматично след 1 час.

Три от инструментите (Редактиране, Изсветляване, Изрязване) работят **изцяло в браузъра** — файлът не се качва никъде.

Няма регистрация и няма ограничение на броя обработки. Всеки инструмент има оценка със звезди (1–5), която може да се даде еднократно.

## Инструментите

### Основни операции с PDF
| Инструмент | Какво прави |
|---|---|
| Обединяване на PDF | Слива няколко PDF файла в един; редът се задава с влачене. |
| Разделяне на PDF | Разделя на отделни файлове — или всяка страница поотделно, или по зададени диапазони (1-3, 4-6). Резултатът е ZIP. |
| Извличане на PDF страници | Запазва само избраните страници в нов файл. |
| Изтриване на PDF страници | Премахва избрани страници. |
| Организиране на PDF страници | Пренареждане на страници чрез влачене. |
| Завъртане на PDF страници | Завъртане на отделни или всички страници. |
| Компресиране на PDF | Намалява размера (Ghostscript). Запазва Document ID, за да остане файлът годен за външно електронно подписване (Evrotrust, eID, Adobe Sign). |
| Черно-бяло PDF | Преобразува в grayscale — по-малък размер, по-евтин печат. |
| Поправка на PDF | Опитва да възстанови повреден или нечетим файл. |
| Групиране в ZIP | Събира няколко PDF файла в един ZIP архив. |

### Редактиране в браузъра
| Инструмент | Какво прави |
|---|---|
| Редактиране на PDF | Редактира съществуващия текст на място (запазва шрифт, размер и цвят), добавя текст, изображения, подписи и фигури; поддържа поставяне от клипборда (изображения, таблици от Excel, текст). |
| Изсветляване на PDF | Яркост, контраст, насищане и острота в реално време — за сканирани или бледи документи. 4 готови профила. |
| Изрязване на PDF | Изрязване с влачене на рамка или с точни полета (mm/pt/in). Без растеризация — текстът остава търсим, линковете се запазват. |

### Защита
| Инструмент | Какво прави |
|---|---|
| Защита на PDF с парола | Добавя парола и ограничения за отваряне/печат. |
| Отключване на PDF | Премахва паролата от файл, за който я знаете. |

### Конвертиране от PDF
PDF към **Word**, **Excel**, **PowerPoint**, **TXT**, **JPG**, **PNG**, **BMP**, **TIFF**.

### Конвертиране към PDF
**Word**, **Excel**, **PowerPoint**, **TXT**, **JPG**, **PNG**, **BMP**, **TIFF** към PDF.

## Техническа част

- **Next.js 15** (Pages Router) + React 18, CSS Modules, `next-i18next` (bg/en)
- **В браузъра:** `pdf-lib`, `react-pdf`, `pdfjs-dist` (от CDN)
- **На сървъра:** Ghostscript (компресиране, grayscale, разделяне), qpdf (парола, брой страници), LibreOffice (офис формати), Python `pdfplumber` + `openpyxl` (PDF → Excel)
- **База:** SQLite (`better-sqlite3`) за оценките със звезди
- **Хостинг:** Docker на VPS, nginx reverse proxy, Let's Encrypt

### Локално стартиране
```bash
npm install
npm run dev     # разработка
npm run build   # production билд
npm run start   # production сървър
```

## Поверителност

Файловете се обработват и изтриват автоматично до 1 час след качване. Инструментите за редактиране, изсветляване и изрязване не изпращат файла към сървър — цялата обработка е локална в браузъра.
